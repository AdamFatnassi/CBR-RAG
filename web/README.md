# Web demo

Open `web/index.html` in any browser (double-click). It needs no complex setup: the engine, the data, the charts, and the RAG explainer are all integrated into the page.

## Pages

- **Overview**: the project in a few numbers and the CBR cycle.
- **Predict a new client**: fill in a client (or start from a typical client or a real test client). The prediction updates live. You see:
  - the past clients behind it (similarity, outcome, reliability);
  - where the similarity comes from, group by group;
  - what one change controlled by the bank (contact type, day, number of calls) would do;
  - **Step 5: AI-Generated Explanation (RAG)**: natural language analytical justification generated by Groq LLM grounded on the 8 closest cases;
  - prompt inspector and in-browser analytical simulation.

  Then enter the real outcome: **Revise** keeps the real outcome as the solution (optionally lowering the reliability of the neighbours that misled the prediction), and **Retain** adds the client to the case base. Predict again and the client comes back first with similarity 1.000.
- **Results**: Experiment 1 (CBR vs k-NN, with 95% intervals), the validation tuning, and Experiment 2 (one by one).
- **How it works**: the five steps (Retrieve, Reuse, Revise, Retain, and RAG Generation), formulas, and weight presets.

## AI Generation (RAG) with Groq

To enable live Groq LLM generation in the web demo:

1. Ensure your `GROQ_API_KEY` is in `.env`:
   ```env
   GROQ_API_KEY=gsk_...
   ```
2. Start the local RAG bridge server:
   ```bash
   python web/rag_server.py
   ```
3. Open or refresh `web/index.html` and click **✦ Generate AI explanation**.

*(If the server is not started, the interface automatically provides a built-in instant analytical simulation, so the demo is always 100% functional).*

## Rebuild after rerunning the experiments

From the project root:

```bash
python src/preprocessing.py
python -m src.experiments
python web/build_web_data.py     # exports data + results to web/data.json
python web/build_web.py          # writes web/index.html
node web/verify_engine.js        # optional: JS engine must agree with src/cbr.py
```
